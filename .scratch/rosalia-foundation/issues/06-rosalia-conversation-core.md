## Agent Brief

**Category:** enhancement
**Summary:** Rosalía talks in the customer's language, uses catalogue facts, escalates to a durable case when unsure, and only applies billing/review actions that the server can verify.

**Current behavior:**
A cheap model returns `{route, reply}`. A nonempty reply is marked `ok` and auto-sent even when route is `human`. Unknown languages score as Spanish. `in_business` can mark the thread active without a Google manager connection. `low_star_ok` and `baja` scripts do not run their side effects from the LLM path. A ten-minute gap drops earlier turns.

**Desired behavior:**
- Launch languages ES/FR/CA/EN stay first-class. Other languages get a best-effort reply in that language; `ok`/`vale` do not reset locale.
- Route `human` creates an open support case, keeps `needs_human`, and auto-sends only a short canned acknowledgement — not the model's long answer as a resolved result.
- Prices, annual alternative, Direct-not-sold, and the pay URL stay server facts in the prompt. The model cannot invent a price.
- `in_business` is refused unless manager invite is `accepted`.
- `low_star_ok` / `low_star_text` call the existing owner-approval path. `baja` records cancellation at period end on the correct Paid Account.
- Recent original messages (newest window) are the context. Do not drop them after ten minutes of silence.

**Acceptance criteria:**
- [ ] German, Arabic and Japanese inbound are not classified as Spanish
- [ ] Model `{route:"human", reply:"…"}` does not auto-send that reply as resolved; a support case exists
- [ ] `low_star_ok` applies owner approval for that account
- [ ] `baja` persists a cancellation action on the Paid Account
- [ ] `in_business` without Google connection does not set phase `active`
- [ ] Annual price is available to the talking prompt as a server fact

**Out of scope:**
- 240-scenario eval set and model bake-off
- Live GBP write
- Stripe Billing 0.7 %
- Direct product tools
